# NoteHub — 08 Zustand

A note management application built with Next.js App Router.  
The project includes note filtering, note details, note creation, SEO metadata, and draft saving with Zustand and localStorage.

## Live Demo

https://08-zustand-alpha-rust.vercel.app/

## Repository

https://github.com/Larimar4you/08-zustand

## Technologies

- Next.js
- React
- TypeScript
- Axios
- TanStack Query
- Zustand
- CSS Modules
- Vercel

## Features

- Notes list with pagination
- Search notes
- Filter notes by tag
- Note details page
- Create note page
- Draft saving with Zustand
- Draft persistence in localStorage
- SEO metadata and Open Graph tags
- Roboto font via `next/font/google`
- SSR and CSR support
